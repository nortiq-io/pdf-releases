# Nortiq PDF — descargas

El editor de PDF que no sube tus documentos a ningún sitio. Para Mac y Windows.

**Descarga la última versión** en [Releases](https://github.com/nortiq-io/pdf-releases/releases/latest):

- **Mac** (Apple Silicon e Intel): el archivo `.dmg`.
- **Windows 10 y 11**: el archivo `-setup.exe`.

Las apps instaladas se actualizan solas: comprueban aquí si hay una versión nueva.

Más información en [nortiq.io/pdf](https://nortiq.io/pdf) · Soporte: soporte@nortiq.io

Este repositorio solo contiene los instaladores; no incluye el código fuente.
